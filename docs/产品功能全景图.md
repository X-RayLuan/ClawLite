# 🦞 ClawLite 产品功能全景图

> 更新时间：2026-05-23

---

## 一、核心产品定位

**一句话描述**：帮你快速安装 + 省钱使用 OpenClaw（AI Agent 平台）的工具，包含安装器 + 路由网关 + 管理后台。

---

## 二、C端功能（用户可见）

### 1. 官网首页 + 下载
- macOS / Windows 双平台安装包（.dmg / .exe）
- 自动检测操作系统，一键下载
- 多语言（EN / ZH / ES / JA / KO）官网

### 2. Setup 向导 ⭐（核心亮点）
**4 步引导，无需终端命令**：

| 步骤 | 说明 |
|------|------|
| OS 检测 | 自动识别 macOS / Windows / Linux |
| 安装向导 | 一键下载运行 ClawLite 安装器 |
| API 配置 | 选择 ClawLite Tokens（5 折）或 BYOK（自备 key） |
| 渠道连接 | Telegram / Web Chat 配置 |

### 3. Pricing 页面
- **20% 低于官方定价**（比官方便宜）
- 支持 OpenAI / Anthropic / MiniMax 全模型
- 公开透明的价格对比表

### 4. 博客系统
- Admin API 发布文章（支持 HTML + 图片上传）
- 公开博客列表页

### 5. 流量渠道
- **Telegram Bot** 接入
- **Web Chat**（内置，无需额外配置）
- **飞书**集成（安装器端）

---

## 三、B端功能（Admin 后台）

### 1. EZRouter Key Pool 管理
- 可视化管理 OpenAI/Anthropic API Keys
- **负载均衡**（按权重分配请求）
- 状态开关、余额告警
- 支持共享 Key 池

### 2. Customer 客户管理
- 客户列表（邮箱搜索、分页）
- **余额调整**（+ / - 调整，记录流水）
- 消费统计（使用量、Token 消耗）
- 单客户流水记录导出

### 3. Usage 消费记录
- 全局 Token 消耗统计
- 按客户维度查看消费

### 4. Admin 用户管理
- 添加/删除管理员账号

### 5. Affiliate 联盟管理
- 联盟成员管理
- 佣金 claim 管理

### 6. Blog 文章管理
- 通过 Admin API 管理博客文章

## 五、技术架构简图

```
用户浏览器
  ├── 官网 (clawlite.ai) — Next.js 多语言站
  ├── 安装器下载 → ClawLite-Installer (Electron)
  │      ├── 飞书/Telegram 渠道配置
  │      └── OpenClaw 本地安装
  │
  ├── API Gateway (clawlite.ai/api/*)
  │      ├── /api/chat/* → OpenClaw
  │      ├── /api/admin/* → Admin 后台
  │      └── /api/usage/* → 用量路由
  │
  └── ClawRouter (Key 池 + 负载均衡)
         ├── OpenAI API (20% off)
         ├── Anthropic API (20% off)
         └── MiniMax API
```
