# ClawLite Blog Image Library

Canonical reusable blog image pool.

## Folder meaning
- `01-install/` — installer entry, launch, setup path
- `02-first-run/` — first success, first useful task
- `03-pricing/` — BYOK, hosted pricing, cost comparison
- `04-reliability/` — setup confidence, validation, repeatability
- `05-comparison/` — OpenClaw vs ClawLite, DIY vs one-click
- `06-checklists/` — checklists, decision cards, preflight visuals
- `07-proof/` — docs/GitHub/proof-backed visuals
- `08-workflows/` — step flows and journey visuals
- `09-brand-utility/` — safe brand utility assets
- `99-archive/` — retired or failed assets

## Rules
- Reusable assets live here.
- Article-specific assets stay under `public/blog/<slug>/`.
- Use descriptive names like `install-entry-mac-windows-v1.jpg`.
- Do not store low-signal video grabs in production categories.
- Move replaced or bad assets into `99-archive/`.
